Política de Privacidad de Agenda Escolar

Última actualización: Octubre de 2026

En Agenda Escolar respetamos y protegemos la privacidad de nuestros usuarios. Esta política de privacidad explica cómo se gestionan los datos en nuestra aplicación.

1. Almacenamiento local de datos

Todos los datos académicos generados en la aplicación (asignaturas, tareas, exámenes y notas) se almacenan exclusivamente de forma local en el dispositivo del usuario mediante una base de datos interna. No recopilamos ni almacenamos ninguna información personal o académica en servidores externos.

2. Publicidad y Recopilación de Datos de Terceros

Para poder ofrecer esta aplicación de forma gratuita, utilizamos servicios de mediación publicitaria y redes de anuncios (a través del SDK de Appodeal). Estos servicios pueden recopilar automáticamente datos técnicos del dispositivo para mostrar anuncios relevantes, tales como:

  • Dirección IP (utilizada para inferir ubicación aproximada).
  • Identificador de Publicidad (Advertising ID / AAID).
  • Datos de rendimiento y registros de errores (crashes).

Puedes consultar la política de privacidad de nuestro proveedor de anuncios en el siguiente enlace: Política de Privacidad de Appodeal.

3. Permisos de la Aplicación

La aplicación solicita únicamente los permisos estrictamente necesarios para su funcionamiento, como conexión a internet (para cargar anuncios) y notificaciones locales (para los recordatorios de exámenes y tareas).

4. Contacto

Si tienes cualquier duda sobre esta política de privacidad, puedes contactar con el desarrollador a través del correo de soporte disponible en la ficha de Google Play Store.
